# `results/paper1_tier_b_eval/` — Evaluation Results

## Aggregated metrics (included in this directory)

Fifteen JSON files and one CSV with per-arm evaluation metrics on the external test set (GSE153515):

- `results_{0.0,0.5}_{42,123,456}.json` — Six fine-tuned Geneformer-V2-104M checkpoints (naive λ = 0.0, CAFT λ = 0.5; seeds 42, 123, 456; epoch 3)
- `results_epoch2_{0.0,0.5}_{42,123,456}.json` — Same six checkpoints at epoch 2
- `results_frozen_gf.json` — Frozen Geneformer-V2-104M (reference)
- `results_hvg_pca.json` — HVG/PCA + linear classifier (reference)
- `summary.csv` — Aggregate summary across arms

All metrics: macro-F1 with 95% bootstrap CI, LAA, differentiation-gradient Spearman ρ, ECE.

## Per-cell predictions and embeddings (not included)

Per-cell arrays (ground-truth labels, predicted labels, 4-class probabilities, and CLS embeddings for all 7 Geneformer-based models on both the external test set and the internal holdout) are stored as compressed NumPy arrays. These files are 31–60 MB each and are **not distributed with the repository** due to size. They are available on request:
